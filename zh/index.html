名字的含义

照片，是我们走过的时光碎屑

Miettes 在法语里是“碎屑、小碎片”的意思。就像吃完可颂留下的碎屑，我觉得照片也是从日常中掉落下来的小小瞬间和记忆碎片。

2026 年 9 月 30 日，三星相册的 OneDrive 同步结束了。从那天起，只存在 OneDrive 里的旧照片从相册中消失，云端照片只能另外打开 OneDrive 应用才能看到。手机空间又有限，没法把所有照片都放在手机里。

所以我只想要一件事：像什么都没发生过一样，继续用昨天还在用的三星相册。

我想守住的东西

不需要重新学习的相册

熟悉的操作，原封不动

One UI 风格的标签栏和大标题、双指缩放 2～12 列、长按拖动多选、上滑查看详情，都跟着三星相册的操作来。点“编辑”会直接打开三星的照片和视频编辑器，备份位置也沿用三星原来在 OneDrive 中使用的 Samsung Gallery 文件夹。

不再多占手机空间

云端照片留在云端直接查看。手机里只缓存缩略图（最多 1GB，从最旧的开始自动清理），原图只在查看时加载或在线播放。

照片安全第一

上传的文件会与 OneDrive 的哈希值比对，确认完整上传。释放设备空间只会删除已确认的照片，而且默认关闭。删除的照片 30 天内都能从回收站恢复；如果一次消失太多照片，还有停止删除的安全机制。

你的照片只在你和 Microsoft 之间

没有任何自建服务器。手机直接与 Microsoft 官方 API 通信，登录也在 Microsoft 的登录页面完成。我不会收到你的照片或账户信息。

能做什么

手机照片和云端照片，同一个画面

一条时间线

把手机照片和 OneDrive 照片按日期合并，相同的照片只显示一张。

标明照片在哪里

已备份、仅设备、仅云端、等待上传、上传失败，用图标和筛选区分。

自动备份

把新照片上传到 OneDrive，大文件支持断点续传。在设备上修改过的照片会替换同一个文件。

用三星编辑器编辑

照片和视频都能直接用三星编辑器打开。只在 OneDrive 的照片会先下载原图再交给编辑器。

故事

自动整理“N 年前的今天”、照片多的日子和旅行。

搜索

按文件名、日期（2024、2024.5）、相册、视频、收藏、GIF 查找。

内置播放器

视频在应用内播放，云端视频无需下载直接在线播放。动态照片和 GIF 也会动。

分享与整理

云端照片也能一次分享多张。还有相册、回收站，以及截图、重复照片、大视频的整理。

安装与初始设置

5 分钟就能继续用起来

  1. 下载并安装 APK。在手机上点下载，并允许安装“未知来源应用”。
  2. 允许访问全部照片和视频。用到哪些权限、为什么用，写在下方。
  3. 菜单 → OneDrive → Microsoft 登录（个人 Microsoft 账户）。
  4. 确认要导入的文件夹。登录后，无论 OneDrive 使用哪种语言，Miettes 都会自动找到 Samsung Gallery 和本机照片文件夹并完成设置。如果你用的是其他文件夹，请在菜单中修改。
  5. 文件夹显示“最新”后（首次索引需要几分钟），打开自动上传新照片，并允许忽略电池优化。

小提示

为避免重复上传，请关闭三星相册的 OneDrive 同步和OneDrive 应用的相机备份。三星已经上传过的照片不会重复上传，只会建立关联。

新版本发布后，用同样的方法覆盖安装即可，数据和登录状态都会保留。

所有版本都可以在发布列表中下载。

第一次打开时会询问的事

权限与 Microsoft 登录

Miettes 第一次打开时会一次性请求所需的权限。下面先说明用了什么、为什么用。通讯录、麦克风、相机、设备位置等权限都不会使用。

手机权限

照片和视频 必需
用于在时间线中显示手机照片并备份新照片。请务必选择全部允许。如果选择“仅限所选照片”，就只会显示选中的照片，新拍的照片也不会自动备份。
照片中的位置信息
用于原样保留照片中的拍摄位置进行备份，并在详情中用地图显示。
通知
在备份进度、需要重新登录、备份积压太久时通知你。关闭通知，应用也能正常运行。
忽略电池优化 可选
让屏幕关闭时备份也不中断。一开始不会询问，可以在菜单 → 权限与电池中开启。之后想重新授予权限，也可以在这里申请。
删除或修改照片时
删除、移动、重命名、旋转时，Android 会再弹出一次确认窗口。这是因为相机等其他应用创建的照片，不允许应用随意修改。

Microsoft 登录

点菜单 → OneDrive → Microsoft 登录，浏览器会打开 Microsoft 登录页面（login.microsoftonline.com）。密码只在 Microsoft 页面上输入，Miettes 看不到。

登录后，Microsoft 会显示权限同意页面。Miettes 请求的权限有三项。

  • 读取和写入文件：用于显示 OneDrive 照片并上传新照片。受 Microsoft 权限机制所限，会显示为整个 OneDrive 的权限，但实际只读取你设置的照片文件夹；写入的也只有备份的照片，以及你删除、重命名或用链接分享的照片。
  • 保持登录：免得每次打开应用都要重新登录。
  • 读取基本个人资料：用于在菜单中显示已登录的账户。

登录信息只保存在手机里的应用存储中，除了 Microsoft 不会发送到任何地方，也不会包含在手机备份中。

想解除连接时，在应用中点菜单 → OneDrive → 退出登录，或在 Microsoft 账户 → 隐私 → “可以访问你数据的应用和服务”中移除权限。

先跟你说清楚

还做不到的事

  • 以 Android 13 及以上的三星 Galaxy 为基准开发和测试（Galaxy S24、Android 13 模拟器）。其他手机尚未测试，三星编辑器联动只在三星手机上可用。
  • 仅支持个人版 OneDrive。工作和学校账户尚未测试。
  • 不是 Play 商店应用。需要手动安装，也没有自动更新，新版本请从本页面下载。
  • 在相机应用中点缩略图，打开的仍然是三星相册。这是三星相机的固定行为，无法更改。
  • 在其他应用（如聊天软件）中添加照片时，Miettes 不会出现在选择器里。只在 OneDrive 的照片，请在 Miettes 里用“分享”发送。
  • 还不支持按照片内容（如“海”“狗”）搜索，也没有人脸识别。
  • 只有设备上的动态照片才会动。只在云端的动态照片会显示为静态图片。
  • 在三星编辑器中保存会生成新的副本，所以编辑后的版本会在时间线中单独显示。
  • 上传遵循 Android 的后台规则，可能不会立即进行。
  • 把在 OneDrive 中删除的照片也从设备上删除时，Android 会弹出一次确认窗口。
