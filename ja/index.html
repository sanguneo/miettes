名前の意味

写真は、私たちが過ごした時間のかけら

Miettes(ミエット)はフランス語で「パンくず、小さなかけら」という意味です。クロワッサンを食べたあとに残るかけらのように、写真も日常からこぼれ落ちた小さな瞬間や、記憶のかけらだと考えました。

2026年9月30日、Samsung ギャラリーの OneDrive 同期が終了しました。その日から、OneDrive にしかなかった昔の写真はギャラリーから消え、クラウドの写真は OneDrive アプリを別に開かないと見られなくなりました。スマホの容量が足りず、すべての写真をスマホに置いておくこともできません。

だから願いはひとつでした。昨日まで使っていた Samsung ギャラリーを、何事もなかったかのように使い続けること。

大切にしたかったこと

新しく覚えることのないギャラリー

使い慣れた操作そのまま

One UI 風のタブと大きなタイトル、ピンチで 2〜12 列に拡大・縮小、長押しドラッグで選択、上にスワイプで詳細表示まで、Samsung ギャラリーの動きに合わせています。編集をタップすると Samsung の写真・動画エディターがすぐ開き、バックアップ先も Samsung が使っていた OneDrive の Samsung Gallery フォルダーをそのまま使います。

スマホの容量はこれ以上使わない

クラウドの写真はクラウドに置いたまま表示します。スマホにはサムネイルだけをキャッシュし(最大 1GB、古いものから自動で整理)、元の写真は見るときだけ読み込むか、ストリーミングします。

写真の安全が最優先

アップロードしたファイルは OneDrive のハッシュと照合し、正しくアップロードされたか確認します。端末の空き容量の確保は確認済みの写真だけを削除し、最初はオフになっています。削除した写真はごみ箱から 30 日間復元でき、一度に大量の写真が消えた場合は削除を止める安全装置もあります。

写真はあなたと Microsoft の間だけに

独自のサーバーはありません。スマホが Microsoft の公式 API と直接通信し、サインインは Microsoft のサインイン画面で行います。私が写真やアカウント情報を受け取る仕組みではありません。

できること

スマホの写真もクラウドの写真も、ひとつの画面で

ひとつのタイムライン

スマホの写真と OneDrive の写真を日付順にまとめ、同じ写真はひとつにして表示します。

写真の保存場所を表示

バックアップ済み、端末のみ、クラウドのみ、アップロード待ち、失敗をアイコンとフィルターで区別します。

自動バックアップ

新しい写真を OneDrive にアップロードし、大きなファイルは続きから再開します。端末で編集した写真は同じファイルとして置き換えます。

Samsung のエディターで編集

写真も動画も Samsung のエディターですぐ開けます。OneDrive にしかない写真は、元ファイルをダウンロードして渡します。

ストーリー

N 年前の今日、写真の多い日や旅行を自動でまとめて表示します。

検索

ファイル名、日付(2024、2024.5)、アルバム、動画、お気に入り、GIF で探せます。

内蔵プレーヤー

動画はアプリ内で再生し、クラウドの動画はダウンロードせずにすぐストリーミングします。モーションフォトや GIF も動きます。

共有と整理

クラウドの写真も複数枚まとめて共有できます。アルバム、ごみ箱、スクリーンショット・重複・大きな動画の整理もあります。

インストールと初期設定

5 分で使い始められます

  1. APK をダウンロードしてインストールします。スマホでダウンロードをタップし、「提供元不明のアプリ」のインストールを許可してください。
  2. 写真と動画へのアクセスをすべて許可します。どの権限を何のために使うかは下にまとめています。
  3. メニュー → OneDrive → Microsoft サインイン(個人用 Microsoft アカウント)。
  4. 取り込むフォルダーを確認します。サインインすると、OneDrive の言語に関係なく Samsung Gallery フォルダーとカメラ ロール フォルダーを自動で見つけて設定します。別のフォルダーを使っている場合はメニューから変更してください。
  5. フォルダーが「最新」になったら(最初のインデックス作成には数分かかります)、新しい写真の自動アップロードをオンにし、バッテリー最適化の除外を許可します。

知っておくと便利

重複アップロードを防ぐため、Samsung ギャラリーの OneDrive 同期とOneDrive アプリのカメラ バックアップはオフにしてください。Samsung がすでにアップロードした写真は再アップロードせず、関連付けるだけです。

新しいバージョンが出たら、同じ方法で上書きインストールしてください。データとサインイン状態はそのまま残ります。

すべてのバージョンはリリース一覧からダウンロードできます。

初回起動時に確認されること

権限と Microsoft サインイン

Miettes は初めて開いたときに、必要な権限をまとめて確認します。何を何のために使うのか、先に書いておきます。連絡先、マイク、カメラ、端末の位置情報などの権限は使いません。

スマホの権限

写真と動画 必須
スマホの写真をタイムラインに表示し、新しい写真をバックアップするために使います。必ずすべて許可を選んでください。「選択した写真のみ」を選ぶと選んだ写真しか表示されず、新しく撮った写真も自動でバックアップされません。
写真の位置情報
写真に含まれる撮影場所を消さずに元のままバックアップし、詳細画面で地図に表示するために使います。
通知
バックアップの進行状況、再サインインが必要なとき、バックアップが長く滞っているときにお知らせします。オフにしてもアプリはそのまま動作します。
バッテリー最適化の除外 任意
画面がオフのときもバックアップが止まらないようにします。最初は確認されず、メニュー → 権限とバッテリーからオンにできます。権限をあとから付与し直したいときも、ここから申請できます。
写真を削除・変更するとき
削除、移動、名前の変更、回転のときに、Android がもう一度確認画面を表示します。カメラなど他のアプリが作成した写真は、アプリが勝手に変更できない仕組みになっているためです。

Microsoft サインイン

メニュー → OneDrive → Microsoft サインインをタップすると、Microsoft のサインイン画面(login.microsoftonline.com)がブラウザーで開きます。パスワードは Microsoft の画面にだけ入力するので、Miettes からは見えません。

サインインすると、Microsoft が権限の同意画面を表示します。Miettes が求める権限は 3 つです。

  • ファイルの読み取り・書き込み:OneDrive の写真を表示し、新しい写真をアップロードするために使います。Microsoft の権限の仕組み上、OneDrive 全体への権限として表示されますが、実際に読み取るのは設定した写真フォルダーだけです。書き込むのも、バックアップした写真と、削除・名前の変更・リンク共有した写真だけです。
  • サインイン状態の維持:アプリを開くたびにサインインし直さなくて済むようにします。
  • 基本プロフィールの読み取り:メニューにサインイン中のアカウントを表示するために使います。

サインイン情報はスマホ内のアプリ領域にだけ保存され、Microsoft 以外にはどこにも送信しません。スマホのバックアップにも含まれないようにしています。

連携を解除したいときは、アプリのメニュー → OneDrive → サインアウトをタップするか、Microsoft アカウント → プライバシー →「データにアクセスできるアプリとサービス」から権限を削除してください。

先にお伝えします

まだできないこと

  • Android 13 以上の Samsung Galaxy を前提に開発・テストしています(Galaxy S24、Android 13 エミュレーター)。他のスマホではテストしておらず、Samsung エディターとの連携は Samsung のスマホでのみ動作します。
  • 個人用 OneDrive 専用です。職場・学校アカウントはテストしていません。
  • Play ストアのアプリではありません。手動でインストールする必要があり、自動更新もないため、新しいバージョンはこのページから入手してください。
  • カメラアプリでサムネイルをタップすると、引き続き Samsung ギャラリーが開きます。Samsung カメラの仕様のため変更できません。
  • 他のアプリ(メッセージアプリなど)で写真を添付するとき、Miettes は選択画面に表示されません。OneDrive にしかない写真は、Miettes の共有から送ってください。
  • 「海」「犬」のような写真の内容での検索や、顔認識はまだありません。
  • モーションフォトが動くのは端末にある写真だけです。クラウドにしかないモーションフォトは静止画として表示されます。
  • Samsung のエディターで保存すると新しいコピーが作られるため、編集版はタイムラインに別に表示されます。
  • アップロードは Android のバックグラウンド制限に従うため、すぐには行われない場合があります。
  • OneDrive で削除した写真を端末からも削除するときは、Android の確認画面が一度表示されます。

散らばったかけらを、もう一度ひとつの場所に
