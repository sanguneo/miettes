삼성 갤러리 OneDrive 동기화가 끝난 뒤를 위한 갤러리

흩어진 사진을,
하나의 시간으로.

폰에 있는 오늘의 사진과 OneDrive에만 남은 몇 년 전 사진을 하나의 타임라인으로 보여 드려요. 사진이 폰에 있든 클라우드에 있든 신경 쓸 필요 없이, 쓰던 삼성 갤러리처럼 열어 보시면 돼요.

관심 가져주셔서 정말 감사합니다.이 페이지까지 와 주신 것만으로도 큰 힘이 됩니다. Miettes는 제가 매일 쓰려고 만든 갤러리예요. 같은 불편을 겪는 분들께도 도움이 되면 좋겠다는 마음으로 공개합니다.

크로아상생쥐 (@croissmouse) 드림

이름의 뜻

사진은 우리가 지나온 시간의 부스러기예요

Miettes(미에뜨)는 프랑스어로 ‘부스러기들, 작은 조각들’이라는 뜻이에요. 크루아상을 먹고 남은 부스러기처럼, 사진도 일상에서 떨어져 나온 작은 순간과 기억의 조각이라고 생각했어요.

2026년 9월 30일, 삼성 갤러리의 OneDrive 동기화가 끝났습니다. 그날부터 OneDrive에만 있던 옛날 사진은 갤러리에서 사라지고, 클라우드 사진은 OneDrive 앱을 따로 열어야 볼 수 있게 됐죠. 폰 용량이 부족해 모든 사진을 폰에 둘 수도 없고요.

그래서 바란 건 하나였어요. 어제까지 쓰던 삼성 갤러리를 아무 일 없던 것처럼 계속 쓰는 것.

제가 지키고 싶었던 것

새로 배울 게 없는 갤러리

손에 익은 경험 그대로

One UI 느낌의 탭과 큰 제목, 핀치로 2~12칸 확대·축소, 길게 눌러 끌어서 선택, 위로 쓸어올리는 상세정보까지 삼성 갤러리의 동작을 따라가요. 편집을 누르면 삼성 사진·동영상 편집기가 바로 열리고, 백업 폴더도 삼성이 쓰던 사진/삼성 갤러리를 그대로 써요.

폰 용량은 더 쓰지 않기

클라우드 사진은 클라우드에 둔 채로 봐요. 폰에는 썸네일만 캐시하고(최대 1GB, 오래된 것부터 자동 정리), 원본은 볼 때만 불러오거나 스트리밍합니다.

사진은 안전이 먼저

올린 파일은 OneDrive의 해시와 비교해 똑같이 올라갔는지 확인해요. 기기 공간 확보는 확인이 끝난 사진만 지우고, 처음에는 꺼져 있어요. 삭제한 사진은 휴지통에서 30일 동안 되살릴 수 있고, 한꺼번에 너무 많이 사라지면 삭제를 멈추는 안전장치도 있어요.

내 사진은 나와 Microsoft 사이에만

별도 서버가 없어요. 폰이 Microsoft 공식 API와 직접 통신하고, 로그인은 Microsoft 로그인 창에서 합니다. 제가 사진이나 계정 정보를 받아 보는 구조가 아니에요.

이런 걸 할 수 있어요

폰 사진도 클라우드 사진도 한 화면에서

하나의 타임라인

폰 사진과 OneDrive 사진을 날짜순으로 합치고, 같은 사진은 하나로 보여줘요.

어디에 있는 사진인지 표시

백업됨, 기기에만, 클라우드에만, 업로드 대기, 실패를 아이콘과 필터로 구분해요.

자동 백업

새 사진을 OneDrive에 올리고, 큰 파일은 이어 올려요. 기기에서 수정한 사진은 같은 파일로 바꿔 올려요.

삼성 편집기로 편집

사진도 동영상도 삼성 편집기로 바로 열려요. OneDrive에만 있는 사진은 원본을 받아서 넘겨줘요.

스토리

N년 전 오늘, 사진이 많은 날과 여행을 자동으로 묶어 보여줘요.

검색

파일 이름, 날짜(2024, 2024.5, 5월), 앨범, 동영상, 즐겨찾기, GIF로 찾아요.

내장 플레이어

영상은 앱 안에서 재생되고, 클라우드 영상은 받지 않고 바로 스트리밍해요. 모션 포토와 GIF도 움직여요.

공유와 정리

클라우드 사진도 여러 장을 한 번에 공유할 수 있어요. 앨범, 휴지통, 스크린샷·중복·큰 동영상 정리도 있어요.

설치와 처음 설정

5분이면 이어 쓸 수 있어요

  1. APK를 받아 설치해요. 폰에서 다운로드를 누르고, “출처를 알 수 없는 앱” 설치를 허용해 주세요.
  2. 사진·동영상 접근을 모두 허용해요. 어떤 권한을 왜 쓰는지는 아래에 적어 뒀어요.
  3. 메뉴 → OneDrive → Microsoft 로그인 (개인 Microsoft 계정).
  4. 가져올 폴더를 확인해요. 로그인하면 OneDrive가 어떤 언어든 삼성 갤러리 폴더와 카메라 앨범 폴더를 자동으로 찾아 설정해요. 다른 폴더를 쓰고 있다면 메뉴에서 바꿔 주세요.
  5. 폴더가 “최신”이 되면(첫 인덱싱은 몇 분 걸려요) 새 사진 자동 업로드를 켜고, 배터리 최적화 예외를 허용해요.

알아두면 좋아요

중복 업로드를 막으려면 삼성 갤러리의 OneDrive 동기화와 OneDrive 앱의 카메라 백업은 꺼 두세요. 삼성이 이미 올린 사진은 다시 올리지 않고 연결만 해요.

새 버전이 나오면 같은 방법으로 덮어 설치하면 돼요. 데이터와 로그인은 그대로 유지돼요.

모든 버전은 릴리즈 목록에서 받을 수 있어요.

처음 열 때 물어보는 것들

권한과 Microsoft 로그인

Miettes는 처음 열면 필요한 권한을 한 번에 물어봐요. 무엇을 왜 쓰는지 미리 적어 둘게요. 연락처, 마이크, 카메라, 기기 위치 같은 권한은 쓰지 않아요.

폰 권한

사진·동영상 필수
폰 사진을 타임라인에 보여주고 새 사진을 백업하려고 써요. 꼭 모두 허용을 골라 주세요. “선택한 항목만”을 고르면 고른 사진만 보이고, 새로 찍은 사진이 자동으로 백업되지 않아요.
사진 속 위치 정보
사진에 담긴 촬영 위치를 지우지 않고 원본 그대로 백업하고, 상세정보에서 지도로 보여주려고 써요.
알림
백업 진행 상황, 다시 로그인이 필요할 때, 백업이 오래 밀렸을 때 알려 드려요. 꺼도 앱은 그대로 동작해요.
배터리 최적화 예외 선택
화면이 꺼져 있을 때도 백업이 멈추지 않게 해요. 처음에는 묻지 않고, 메뉴 → 권한과 배터리에서 켤 수 있어요. 권한을 나중에 다시 주고 싶을 때도 여기서 요청하면 돼요.
사진을 지우거나 바꿀 때
삭제, 이동, 이름 바꾸기, 회전을 할 때 Android가 확인 창을 한 번 더 띄워요. 카메라 같은 다른 앱이 만든 사진은 앱이 마음대로 바꿀 수 없게 되어 있어서 그래요.

Microsoft 로그인

메뉴 → OneDrive → Microsoft 로그인을 누르면 Microsoft 로그인 화면(login.microsoftonline.com)이 브라우저로 열려요. 비밀번호는 Microsoft 화면에만 입력하니까 Miettes는 볼 수 없어요.

로그인하면 Microsoft가 권한 동의 화면을 보여줘요. Miettes가 요청하는 권한은 세 가지예요.

  • 파일 읽기·쓰기: OneDrive 사진을 보여주고 새 사진을 올리려고 써요. Microsoft 권한 구조상 OneDrive 전체에 대한 권한으로 표시되지만, 실제로 읽는 건 설정한 사진 폴더뿐이에요. 쓰는 것도 백업한 사진, 그리고 지우거나 이름을 바꾸거나 링크로 공유한 사진뿐이에요.
  • 로그인 유지: 앱을 열 때마다 다시 로그인하지 않게 해요.
  • 기본 프로필 읽기: 메뉴에 로그인한 계정을 보여주려고 써요.

로그인 정보는 폰 안의 앱 저장소에만 남고, Microsoft 말고는 어디로도 보내지 않아요. 휴대폰 백업에도 포함되지 않게 해 뒀어요.

연결을 끊고 싶으면 앱 메뉴 → OneDrive → 로그아웃을 누르거나, Microsoft 계정 → 개인정보 → “데이터에 액세스할 수 있는 앱 및 서비스”에서 권한을 없애면 돼요.

미리 말씀드릴게요

아직 안 되는 것들

  • Android 13 이상, 삼성 갤럭시 기준으로 만들고 테스트했어요(갤럭시 S24, Android 13 에뮬레이터). 다른 폰은 테스트해 보지 못했고, 삼성 편집기 연동은 삼성 폰에서만 돼요.
  • 개인 OneDrive 전용이에요. 회사·학교 계정은 테스트하지 않았어요.
  • Play 스토어 앱이 아니에요. 직접 설치해야 하고, 자동 업데이트가 없어서 새 버전은 이 페이지에서 받아 주세요.
  • 카메라 앱에서 썸네일을 누르면 여전히 삼성 갤러리가 열려요. 삼성 카메라가 정해 둔 동작이라 바꿀 수 없어요.
  • 다른 앱(카톡 등)에서 사진을 첨부할 때 Miettes가 선택기로 뜨지는 않아요. OneDrive에만 있는 사진은 Miettes에서 공유하기로 보내 주세요.
  • “바다”, “강아지” 같은 사진 내용 검색과 얼굴 인식은 아직 없어요.
  • 모션 포토는 기기에 있는 사진만 움직여요. 클라우드에만 있는 모션 포토는 정지 사진으로 보여요.
  • 삼성 편집기에서 저장하면 새 사본이 생겨서, 타임라인에 편집본이 따로 보여요.
  • 업로드는 Android 백그라운드 정책을 따라서 바로바로 올라가지 않을 수 있어요.
  • OneDrive에서 지운 사진을 기기에서도 지울 때는 Android 확인 창이 한 번 떠요.

흩어진 조각들을, 다시 한곳에서

그 조각들이 어디에 흩어져 있든, 한곳에서 편하게 다시 꺼내 볼 수 있었으면 했어요. 써 보시고 불편한 점이나 바라는 점이 있으면 편하게 알려 주세요. 하나하나 소중히 읽겠습니다.
